# Logy v0.1.0

First public release of **Logy** — a Windows-first local development journal daemon and CLI.

## Highlights

- **Local daemon** with exclusive lock, rotating logs, and named-pipe control (no TCP)
- **Git discovery** under configured roots (`.git`), with persistent project ignore/unignore
- **Collectors** for Git (commit/branch/status/diffstat), `logy exec` terminal events, optional agent JSON/JSONL, and optional filesystem changes (off by default)
- **Offline queries**: `today` / `week` / `month`, `events`, `ask`, `summarize`, `note`
- **Opt-in AI** via `summarize --ai` / `ask --ai` (redacted context; API keys never stored in SQLite)
- **Maintenance**: `purge` retention, Windows `startup enable/disable`, `doctor`

## Install

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.ps1 | iex
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.sh | bash
```

Pin a version with `LOGY_VERSION=v0.1.0`. Forks can set `LOGY_GITHUB_REPO=owner/name`.

## Quick start

```text
logy version
logy doctor

logy root add C:\dev
logy start          # background daemon; terminal returns
logy status
logy exec -- go test ./...
logy today
logy ask "o que eu fiz ontem?"
logy stop            # or shut down the computer

logy startup enable
logy purge --older-than 2025-01-01 --dry-run
```

Optional: set `LOGY_HOME` to isolate config/data (default `~/.logy`).
Use `logy start --foreground` only when debugging.

## What's included

### Daemon & control

- Singleton lock file, batch flush to SQLite (WAL)
- Named pipe `\\.\pipe\logy-<user>` (Unix socket fallback)
- Commands: `start`, `status`, `stop`, `reload` (via pipe)

### Discovery & projects

- `root add` / `root list`
- `project list` / `show` / `ignore` / `unignore`
- Bounded depth scans; ignored projects persist across rediscovery

### Collectors

- Git snapshot events per discovered repo
- `logy exec -- <cmd> [args]` (argv only, stdin discarded)
- Agent session reader (JSON/JSONL)
- Filesystem collector available but disabled by default

### Reports & privacy

- Deterministic Portuguese-friendly `ask` period/project parsing
- Redaction of `token` / `password` / `api_key`
- AI only when explicitly requested and configured (`ai.enabled`, endpoint, `keyEnv`)

### Distribution

- GitHub Releases via GoReleaser (Windows / macOS / Linux, amd64 + arm64)
- SHA256 checksum verification on install
- `logy version` reports release version from ldflags

## Notes

- First target is **Windows**; other OSes are built and installable
- `logy start` detaches a background process; `logy stop` or OS shutdown ends it. Use `logy startup enable` for login registration on Windows.
- Requires Go only for building from source; releases are static binaries (`CGO_ENABLED=0`)
