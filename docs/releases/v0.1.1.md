# Logy v0.1.1

Patch release: the daemon now runs **in the background** after `logy start`.

## Fix / change

- `logy start` spawns a detached process and returns the terminal immediately (`logy daemon started`)
- Closing the starter terminal no longer stops Logy
- Stop with `logy stop` from any terminal, or when the computer shuts down
- `logy start --foreground` keeps the old blocking mode for debugging
- Duplicate `start` still fails with *already running*

## Install / update

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.ps1 | iex
```

Pin this release:

```powershell
$env:LOGY_VERSION = "v0.1.1"
irm https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.ps1 | iex
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.sh | bash
# or
LOGY_VERSION=v0.1.1 curl -fsSL https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.sh | bash
```

## Verify

```powershell
logy version
logy start
logy status
# close this terminal, open another
logy status
logy stop
```

From a local dev build:

```powershell
.\scripts\build-dev.ps1
.\logyDEV.exe start
.\logyDEV.exe status
.\logyDEV.exe stop
```
