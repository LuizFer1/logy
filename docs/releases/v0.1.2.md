# Logy v0.1.2

Patch release: first-run root setup, self-update, and a quieter Windows start.

## Highlights

- **First `logy start`**: if no roots exist, asks for folders (trabalho / startups / pessoal…) — one path per line, empty line to finish
- **`logy root add`** without a path enters the same interactive loop
- **`logy update` / `update --yes` / `update --check`**: upgrade from GitHub Releases with SHA256 verification (Clocky-style)
- **No flashing console** on `logy start` (Windows `CREATE_NO_WINDOW`)
- **Hidden login autostart** via VBScript instead of a visible `cmd.exe`
- Discovery depth default raised to **5**; stops under a found `.git` but still finds sibling/nested repos

## Install / update

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.ps1 | iex
```

If already installed:

```powershell
logy update --yes
```

Pin this release:

```powershell
$env:LOGY_VERSION = "v0.1.2"
irm https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.ps1 | iex
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.sh | bash
# or
logy update --yes
```

## Verify

```powershell
logy version
logy start
# first run: enter C:\trabalho, C:\startups, C:\pessoal, then blank line
logy root list
logy status
logy stop
logy update --check
```
