# Logy v0.1.3

Patch release: detailed help and short command aliases.

## Highlights

- **`logy help`** — overview of all commands with aliases
- **`logy help <command>`** — detailed usage (accepts aliases too, e.g. `logy help str`)
- **Short aliases** for faster typing:

| Command | Alias | Command | Alias |
|---------|-------|---------|-------|
| start | str | summarize | sm |
| stop | stp | events | ev |
| status | st | note | nt |
| today | td | exec | ex |
| week | wk | ask | ak |
| month | mo | purge | pg |
| root | rt | startup | su |
| project | pr | doctor | doc |
| version | ver | update | up |
| help | h | | |

## Install / update

**Windows (PowerShell):**

```powershell
logy update --yes
```

Or:

```powershell
irm https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.ps1 | iex
```

Pin this release:

```powershell
$env:LOGY_VERSION = "v0.1.3"
irm https://raw.githubusercontent.com/LuizFer1/logy/main/scripts/install.ps1 | iex
```

## Verify

```powershell
logy version
logy help
logy help start
logy help sm
logy str
logy st
logy stp
```
